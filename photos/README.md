# Product photos for the Reels

Drop a product photo here and the next Reel for that deal shows it on an elegant card.

**How to add one:** on GitHub open this `photos` folder → **Add file** → **Upload files** → drag the photo in → **Commit changes**.

**How to name it** (either way works):
- With a few words from the product name, e.g. `wyze cam.jpg` or `ninja air fryer.jpg`.
  Every word in the file name must appear in the deal title. Longer names win if two photos match.
- With the deal's id from the website (the part after `#d-` in the deal link), e.g. `3f9a1c2b7e.jpg`.

Deals that have a photo get made into Reels first.

**Use only photos you are allowed to use:** your own phone photos, or images a brand or affiliate
program (Levanta, Archer, Walmart/Target via Impact) gives you for promotion.
Do not download Amazon product images: Amazon's rules don't allow it.
